# Open Questions

Diambil dari Bagian 13 PRD. Tidak ada nilai bisnis yang diarang di source code.

- Identitas usaha untuk struk: nama, logo, alamat, kontak.
- Tarif, minimum berat, durasi normal/express, biaya express, dan pembulatan rupiah.
- Paket langganan: kuota, masa aktif, layanan, carry-over, pembatalan.
- DP: persentase serta nilai minimum/maksimum.
- Provider dan akun merchant QRIS/transfer; kebijakan expiry/refund.
- Provider WhatsApp Business, template, opt-in, dan anggaran pesan.
- Slot, jam operasional, area/capacity antar-jemput, serta biaya per kondisi.
- Pajak, diskon, promo, dan perubahan/pembatalan slot pelanggan.
- Hosting, domain/TLS, backup cloud, monitoring, serta anggaran.
- Kebijakan retensi data pribadi/transaksi dan Q90 konfigurasi.
